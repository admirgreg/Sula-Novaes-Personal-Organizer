# Site Sula Novaes | Personal Organizer

Estrutura:
- index.html: textos e estrutura da página
- css/style.css: visual (cores da marca no começo, em :root)
- js/main.js: o "antes e depois" (projetos no array `cases`)
- assets/logo.png: logo em bege com fundo transparente

Para ver no computador: abra a pasta no VS Code e use a extensão Live Server.
Para publicar: arraste a pasta inteira em app.netlify.com/drop.
